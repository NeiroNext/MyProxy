# Smart Proxy Switcher

Расширение Chrome, которое позволяет гибко управлять подключением через прокси.

## Возможности

- Быстрое переключение режимов: без прокси, глобальный прокси, автопрокси и «Автопрокси +» (весь трафик через прокси по умолчанию с учётом исключений из правил).
- Поддержка нескольких профилей прокси с отдельными настройками.
- Тонкая настройка доменов и отдельных адресов: для каждого можно указать режим и нужный профиль прокси.
- Быстрое назначение профиля прокси для текущего сайта прямо из всплывающего окна.
- В режиме автопрокси можно выбрать базовое поведение: обходить прокси по умолчанию или, наоборот, пропускать весь трафик через профиль по умолчанию, а исключения задавать в списке доменов.
- Массовое редактирование списка доменов: выбирайте несколько записей и задавайте для них нужный профиль или удаляйте одним действием.
- Сортировка правил по домену/адресу, профилю, режиму и времени добавления (в обе стороны).
- Поддержка масок вида `*.example.com` и приоритезация более конкретных правил при совпадении.
- Отслеживание проблемных доменов на странице: сетевые ошибки и ответы 4xx/5xx по всем запросам, включая XHR, fetch, скрипты и картинки, а не только сам документ.
- Для каждого проблемного домена видно число повторов, тип запроса и то, какое правило действует сейчас — без прокси или через конкретный профиль. Это помогает решить, нужно ли включить прокси или выбрать другой профиль.
- Список ошибок относится к текущей загрузке страницы и очищается при переходе или перезагрузке вкладки.
- Индикация количества ошибок прямо в всплывающем меню для быстрого доступа к проблемным доменам.
- Предупреждение в всплывающем окне, если выбранный профиль прокси не заполнен: расширение прямо сообщает, что трафик идёт напрямую, вместо тихого отката.
- Экспорт и импорт настроек для резервного копирования или переноса.

## Структура расширения

Все файлы расширения находятся в каталоге [`extension`](extension/):

- `manifest.json` — описание разрешений и точек входа.
- `background.js` — управление режимом прокси и обработка ошибок подключения.
- `popup.*` — всплывающее окно с переключателями режимов и списком ошибок.
- `options.*` — страница настроек с профилями, доменами и импортом/экспортом.
- Расширение построено на Manifest V3 и использует сервис-воркер для обновления PAC-скриптов и прокси-настроек.

## Установка

1. Откройте Chrome и перейдите на страницу `chrome://extensions`.
2. Включите режим разработчика (Developer mode).
3. Нажмите «Load unpacked» / «Загрузить распакованное расширение».
4. Укажите папку `extension` в корне репозитория.
5. После загрузки нажмите на иконку расширения, чтобы выбрать нужный режим работы.

Настройки и выбранные режимы сохраняются в браузере автоматически.
